# 挑战者号发射决策：真实案例测试包

这是一套用于测试“真源 ProofMate”的公开案例材料。事实依据来自 NASA 的罗杰斯委员会公开报告；文件经过中文整理，保留了来源链接，但不代表 NASA 原始中文表述。

## 推荐实验顺序

1. 第一次直接上传 `01-挑战者号待审查案例.pdf`。这是当前推荐入口，能够同时验证 PDF 正文提取和原文件预览。
2. 等档案生成后，运行“本地分析仪”，观察它是否指出低温、历史侵蚀和决策信息链缺少证据。
3. 再运行“云端复核仪”，检查每条结果是否包含结论、原文、风险边界和补证动作。
4. 选择风险主张，上传 `02-NASA公开证据摘录.txt`，观察系统将材料判断为支持、冲突还是无关。
5. PDF 本身包含可复制正文，因此会由 PDF.js 在浏览器读取，不会滥用 OCR。需要测试 OCR 时，勾选授权后单独上传 `03-NASA-O形环风险图表.jpg`，检查 TextIn xParse 是否提取图中文字，并在“原始材料与提取结果”中展示。
6. 人工核对证据关系，点击确认，检查主张状态、证据关系板和处理轨迹是否同步更新。

## 预期观察

- “现有证据足以支持低温发射”应被识别为高风险或冲突主张。
- NASA 摘录不应被模型改写成材料中不存在的事实。
- 图表 OCR 可能存在少量英文字符误识别，这应被视为待人工核对的提取文本，而不是已确认事实。
- 模型建议只有在你点击确认后才应进入档案。
