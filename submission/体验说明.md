# 真源 ProofMate · 体验说明

## 先看作品

解压后进入 `作品展示/应用源码`。安装 Node.js 20 或更新版本，在该目录运行：

```powershell
npm install
npm run dev
```

打开终端给出的本地地址。首页点“查看案例展示”，选择一个案例并点“打开”，即可在无密钥、无模型下载的情况下体验主张索引、证据关系板、风险说明和摘要导出。案例界面会标明“演示模式”；它不代表实时模型调用。

要审查自己的材料，回到首页点“开始审查我的材料”，选择文本、PDF 或图片文件。页面先展示提取出的文字和来源，再由使用者决定是否进行本地分析或云端复核。模型建议不会自动变成证据：找到原文后，仍需人工确认支持或冲突关系。页面“评分怎么算”解释进度分的权重；它不是事实正确率。

## 启用本地模型

本地模型权重体积约数 GB，未放入 ZIP。项目使用 OpenVINO Qwen3-4B INT4，默认 CPU；以下命令在 `作品展示/应用源码` 目录运行：

```powershell
py -3.12 -m venv local-ai/.venv
local-ai/.venv/Scripts/python.exe -m pip install -e "local-ai[dev,openvino]"
local-ai/.venv/Scripts/python.exe scripts/download_openvino_model.py --accept-download
local-ai/.venv/Scripts/python.exe -m uvicorn app.main:app --app-dir local-ai --host 127.0.0.1 --port 8787
```

访问 `http://127.0.0.1:8787/health` 检查服务，再在真实材料页面点“使用端侧模型分析”。模型加载需要时间；未安装或服务不可用时页面会明确提示。实机测试记录见 `AI实践佐证/OpenVINO实机测试.md`，单机结果不代表所有电脑的速度。

## 启用云端复核和扫描件识别

在页面右下角打开“模型与 OCR 设置”，填写自己的百炼 API Key，即可按需运行千问复核。云端请求会发送待复核主张和必要的上传原文片段；不要上传无权处理的材料。密钥不包含在作品包中。

图片或扫描 PDF 的 OCR 使用 TextIn xParse。先安装 `xparse-cli`，再在同一设置页填写自己的 TextIn App ID 和 Secret Code：

```powershell
npm i -g xparse-cli
```

OCR 的作用是把扫描材料转为可查看、可定位的文字；它本身不判断证据关系。文本型 PDF 由浏览器直接提取，不需要调用 OCR。

## 源码与验证

`作品展示/应用源码` 内含前端、云端适配器、本地服务、测试和构建文件。可运行 `npm test`、`npm run build`；安装对应 Python 依赖后可运行 `python -m pytest local-ai/tests -q`。项目 GitHub 地址：<https://github.com/LucianaiB2004/proofmate>。
