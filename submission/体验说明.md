# 真源 ProofMate 体验说明

## 最快体验（推荐评审使用）

1. 解压作品包，进入 `作品展示/应用源码`。
2. 安装 Node.js 20 或更高版本。
3. 运行 `npm install`，再运行 `npm run dev`。
4. 浏览器打开终端显示的本地地址。
5. 点击“体验示例项目”，等待约 2.4 秒进入证据驾驶舱。
6. 选择不同主张查看证据与风险。
7. 点击“补充 30 天对照实验”，观察健康度从 68 提升至 85。
8. 点击“导出答辩摘要”取得 Markdown 报告。

该流程不需要账号、API Key 或下载模型。页面会明确标记为“演示模式”，所有数据均为本届作品专用原创样例。

## 启用百炼 Qwen

复制 `.env.example` 为 `.env.local`，填写：

```env
DASHSCOPE_API_KEY=你的百炼APIKey
QWEN_MODEL=qwen-plus
```

密钥由 Vite 本地服务端代理读取，不会打入浏览器构建产物。进入驾驶舱后点击“检测并分析当前材料”即可验证；未配置时明确显示“未配置 API Key”。

## 启用 OpenVINO 端侧模型（可选）

推荐模型：Qwen3-4B INT4 OpenVINO；推荐设备：CPU；预计需要数 GB 下载空间。作品不会自动下载模型。

```powershell
py -3.12 -m venv local-ai/.venv
local-ai/.venv/Scripts/python.exe -m pip install -e "local-ai[dev,openvino]"
local-ai/.venv/Scripts/python.exe scripts/download_openvino_model.py --accept-download
local-ai/.venv/Scripts/python.exe -m uvicorn app.main:app --app-dir local-ai --host 127.0.0.1 --port 8787
```

访问 `http://127.0.0.1:8787/health` 查看服务和模型状态。当前电脑为 AMD Ryzen 7 5800H，OpenVINO 默认使用 CPU，不宣称具备 Intel NPU。

本机已完成真实推理：本次首次加载并分析 18.14 秒；三次热启动为 8.75、8.43、9.09 秒，中位数 8.75 秒；50ms 采样的进程峰值内存约 4.75GB。该结果仅代表当前机器本次运行。运行 `local-ai/.venv/Scripts/python.exe scripts/benchmark_openvino.py` 可复测。


## 数据与安全边界

- 原始文件默认只在浏览器和本机处理。
- 只有明确启用云端能力后，必要片段才会发送给 Qwen。
- 演示回放、端侧推理和云端推理在界面中分别标注。
- 输出用于辅助整理与核验，不替代学术审稿和人工判断。
