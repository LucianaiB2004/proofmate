# 关键代码路径

| 能力 | 文件 | 可检查的行为 |
|---|---|---|
| 材料提取 | `src/features/onboarding/extractFileText.ts` | 文本型 PDF 在浏览器内提取；图片与扫描件走 OCR 路径 |
| 材料建档 | `src/features/onboarding/buildImportedAudit.ts` | 从提取文字建立材料与主张档案 |
| 本地模型 | `local-ai/app/model_runtime.py` | OpenVINO GenAI 延迟加载、审查与证据关系判断 |
| 本地 API | `local-ai/app/main.py` | 健康检查与分析接口 |
| 千问复核 | `server/qwenClient.ts` | 百炼调用、编号主张、结构化字段约束和异常状态 |
| 多轮合并 | `src/domain/reviewMerge.ts` | 重复发现合并、原文匹配与待人工确认状态 |
| 证据评分 | `src/domain/audit.ts` | 来源核验、人工确认及公开的加权计算 |
| 产品交互 | `src/features/audit/AuditDashboard.tsx` | 主张、关系板、云端复核和补证闭环 |
| 自动化检查 | `src/**/*.test.*`、`local-ai/tests/`、`tests/e2e/` | 单元、服务与浏览器场景 |

所有相对路径以 `作品展示/应用源码` 为起点。模型权重与用户密钥不包含在作品包里。
