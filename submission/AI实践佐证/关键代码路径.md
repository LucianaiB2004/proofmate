# 关键代码路径

| 能力 | 路径 | 验证方式 |
|---|---|---|
| OpenVINO 本地模型 | `local-ai/app/model_runtime.py` | 模型存在时延迟加载 `openvino_genai.LLMPipeline` |
| 本地 API | `local-ai/app/main.py` | `/health`、`/v1/local/model`、`/v1/local/analyze`、`/v1/local/embed` |
| 百炼 Qwen | `server/qwenClient.ts` | 缺 Key、超时、HTTP 错误、结构化成功四种结果 |
| 证据评分 | `src/domain/audit.ts` | 权重函数、不可变补证、重复证据去重 |
| 证据驾驶舱 | `src/features/audit/` | 主张、图谱、风险、处理轨迹和补证交互 |
| 自动验证 | `src/**/*.test.*`、`local-ai/tests/`、`tests/e2e/` | 单元、API 和 Chrome 端到端测试 |
