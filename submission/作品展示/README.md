# 真源 ProofMate · 作品展示

参赛名称：**真源：端云协同可信证据系统**

一句话：AI 发现关系，人审阅并盖章确认；把论文、代码、数据和截图变成可追溯、可修复的证据档案。

作品形态：React Web Demo + FastAPI/OpenVINO 可选端侧服务 + 百炼 Qwen 可选云端适配器。

已完成百炼 `qwen-plus` 与 OpenVINO Qwen3-4B INT4 的真实联调；实时模型建议统一进入“待人工确认”纸条，不自动冒充已确认事实。`界面截图-OpenVINO实机.png` 展示端侧模型结果进入产品界面。

视觉说明：界面使用“数字档案室 × 像素仪器”语言。纸纹、空心印泥和像素扫描仪是无文字装饰，档案编号、主张、状态和审核结论全部由真实 HTML/CSS 呈现，素材加载失败也不影响操作。

推荐体验路径：运行应用 → 点击“体验示例项目” → 查看准确率冲突 → 补充 30 天对照实验 → 观察健康度从 68 提升至 85 → 导出答辩摘要。

完整运行步骤见作品包根目录的 `体验说明.md`。
