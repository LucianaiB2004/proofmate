# 真源 ProofMate「数字档案室 × 像素仪器」视觉重构

## 目标

把当前偏标准 AI/SaaS 仪表盘的界面，重构成一个具有学生作者感、研究过程感和比赛记忆点的数字档案工具。保留全部业务功能、真实 Qwen/OpenVINO 链路、响应式能力和可访问性，不用大面积生成图片掩盖产品本身。

核心观感：**一个认真、偏执、很会整理证据的学生，亲手做出了一套数字研究档案系统。**

## 视觉原则

1. 人的痕迹优先：档案编号、日期、手写圈注、盖章、回形针、装订孔和纸张层级，体现真实研究过程。
2. 科技感局部化：像素字体、扫描光标、状态灯和微型仪器只用于运行时、进度和机器状态，不铺满全屏。
3. 信息仍是主角：主张、来源、风险和补证关系必须比装饰更醒目。
4. 生成资产克制：仅生成无文字的纸张纹理、证据印章底纹和像素扫描仪插画；所有中文文字继续由 HTML/CSS 排版。
5. 不伪装真实性：AI 结果、演示回放、实时端侧与云端状态继续明确区分。

## 视觉系统

### 色彩

- 纸张底色：暖灰白 `#EEE9DE`，替代大面积纯黑。
- 墨色：炭黑 `#171717`，用于正文和结构线。
- 审核红：`#D63B32`，只用于风险、圈注、印章和主要操作。
- 仪器绿：`#147D68`，用于 OpenVINO、本地处理和已证实状态。
- 铅笔灰：`#74716A`，用于说明和非活跃信息。
- 深色区域只保留给证据图谱、运行时仪器屏和局部对比块。

### 字体

- 中文标题使用有编辑感的粗黑体组合，不使用渐变字或发光字。
- 正文保持清晰的系统无衬线字体。
- 编号、文件路径、状态与时间使用等宽字体。
- 像素字体仅用于小型 DEVICE/CLOUD/READY 标签，不承担长文本。

### 材质与形状

- 卡片像档案纸页：轻微错位、硬边框、纸张阴影和装订孔。
- 控件像研究工具：标签贴、审核章、夹子和量尺，而非玻璃拟态卡片。
- 圆角从当前大面积 20px 降至 2–8px；避免标准 AI Dashboard 外观。

## 页面设计

### 首屏：待审项目档案袋

- 版式由居中 Hero 改为左右错位的档案封面。
- 左侧包含产品名、价值主张、参赛编号、日期和“学生作品”档案标签。
- 右侧为材料投递口：虚线裁切边、回形针、支持格式清单和真实文件选择。
- “体验示例项目”表现为盖章式主操作。
- 背景使用低对比纸张纤维；不出现大面积抽象 AI 光效。

### 扫描过程：三段像素仪器

- 三个阶段表现为桌面仪器读数条：材料清点、隐私检查、模型核验。
- 使用像素状态灯和单行进度扫描，不使用通用加载骨架屏。
- 真实材料与样例回放继续显示不同标题。

### 驾驶舱：研究档案桌

- 顶部是项目卷宗抬头、档案编号、导出按钮和真实运行模式。
- 健康度由常见圆环改为“审核章 + 四条证据量尺”。
- 主张列表改成带编号和状态批注的索引卡。
- 证据图谱表现为便签、编号标签和连接线；保留可访问 SVG 文本替代。
- 风险面板像审稿人的边栏批注：红笔圈注、原始片段、修复建议。
- 补证成功出现一次短暂“证据闭环”盖章动画，并尊重 reduced-motion。

### 运行时：端云双仪器

- OpenVINO 与百炼 Qwen 分别表现为本地分析仪和云端复核仪。
- 使用真实状态灯、运行时间和模型名称；不可用时显示具体原因。
- 实时模型结果放在“待人工确认”纸条中，不自动混入已确认事实。

## 生成视觉资产

只生成以下无文字资产：

1. `paper-fiber.webp`：极淡暖灰纸张纤维，可平铺，不抢正文。
2. `evidence-seal.webp`：不包含文字的红色圆形印泥纹理，由 CSS 叠加“证据闭环”等文字。
3. `pixel-scanner.webp`：透明背景的小型像素扫描仪，限定用于首屏或运行时角落。

生成资产必须压缩、提供 CSS 回退色，并确保加载失败时界面仍完整。

## 保留与不做

保留：真实文件导入、PDF 解析、样例回放、证据评分、图谱、补证、导出、Qwen/OpenVINO 实时调用、移动端布局、打印样式。

不做：人物头像、3D 大场景、全屏生成背景、复杂游戏化、音效、账号系统、数据库或与视觉重构无关的新功能。

## 验收标准

- 首屏、扫描、驾驶舱、风险选择、补证完成、实时 OpenVINO 结果六个状态视觉统一。
- 1440×900 和 390×844 均无整页横向溢出，主要按钮始终可用。
- 页面不依赖生成资产才能阅读和操作。
- `prefers-reduced-motion` 下关闭盖章和扫描动画。
- 保持现有 27 项前端测试、4 项 E2E、9 项 Python 测试通过。
- 新增视觉语义测试：档案编号、学生作品标签、证据审核章和双仪器标题可被访问性查询。
- 重新生成封面与演示截图，并人工检查全尺寸和缩略图。
- 最终 ZIP 不包含 API Key、本地模型、虚拟环境或临时缓存。

## 比赛表达

新的视觉不是“复古装饰”，而是产品逻辑的一部分：AI 负责发现关系，人负责审阅和盖章确认。档案、批注与印章把“可信、可追溯、可负责”变成评委第一眼就能理解的视觉语言。
