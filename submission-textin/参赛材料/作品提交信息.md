## 作品描述

### 1. 要解决的问题

学生做答辩、科研立项或项目申报时，材料里常有许多“看起来合理”的结论，但结论背后的数据、出处和原文并没有对齐。人工逐页翻找 PDF、扫描表格和图片，既慢，也容易把“模型判断”误当成“真实证据”。真源 ProofMate 面向这一环节，把材料中的主张、证据、冲突和待补项整理成一份可以逐条回查的档案。

### 2. 怎么使用

用户上传 PDF、图片或扫描件后，系统先读取材料正文：文本型 PDF 在浏览器内提取；图片和扫描 PDF 交给 TextIn xParse 转成可搜索、可引用的文字。随后 OpenVINO 本地模型完成隐私优先的第一轮审查，Qwen 只复核仍未解决的主张。每条结论都会显示证据摘录、材料来源、支持或冲突关系、评分组成与下一步补证建议，用户确认后再写入档案。

### 3. TextIn xParse 的作用

xParse 是整个证据链的“入口”。它把原本只能看、不能检索的扫描材料变成带结构的 Markdown，让后续模型能够引用具体文字，而不是只凭文件名或印象判断。系统保留原始文件名、提取方式和 OCR 结果；OCR 只负责“读出来”，不会越权判断结论真假。本次在 ProofMate 项目开发过程中，通过 WorkBuddy 使用 NASA 挑战者号 O 形环风险图表完成 Markdown 与 JSON 两次真实解析，完整调用分别耗时 3813 ms 和 4230 ms，并保留服务端状态、配额变化和文件哈希。

### 4. 带来的价值

传统流程需要在原文、聊天窗口和笔记之间反复切换；ProofMate 把“上传—解析—初审—复核—补证—归档”放到同一条可见流程里。用户可以直接看到哪些结论已有证据、哪些证据相互冲突、还应该补什么材料。系统不把 AI 输出包装成事实，而是要求每个结论回到原文证据，并把最终确认权留给用户。
