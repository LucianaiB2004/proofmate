## 使用边界

- 不使用包含本机账号信息的原始全屏截图作为公开素材；
- 不在图片或文章中展示 API Key、Secret Code 或其他完整凭证；
- “真实调用成功”应与 `../workbuddy-development/02-xParse真实调用记录.md`、`xparse-output/xparse-run-record.json` 一起引用；
- WorkBuddy 的作用应客观表述为：在 ProofMate 开发过程中读取项目、加载 Skill、执行真实解析、协助代码审查与生成开发文档。不要写成“WorkBuddy 是 ProofMate 的产品功能”或“用户需要通过 WorkBuddy 使用 ProofMate”；最终产品运行时仍由 ProofMate 自己完成材料读取、证据审查与人工确认。
